OpenBrowserAgent 把 AI 智能体放进浏览器的侧边栏。你可以就当前页面提问、围绕一个问题在网上调研，或者把浏览器任务交给它。智能体会阅读页面、点击、输入，并在标签页之间切换，每一步都在你眼前进行。

模型由你自己提供：可以是用你自己的 API Key 连接的云端 AI 提供商，也可以是在你自己电脑上运行的模型。OpenBrowserAgent 没有账号，也没有自己的服务器。你的内容只会发送到你自己配置的服务；其他服务器上的 AI 提供商，在你为它单独同意之前收不到任何内容。你自己电脑或本地网络上的模型无需许可。

【能做什么】

• 就一个页面或多个标签页提问：总结、对比、解释，以及附带可点击来源的答案。
• 让智能体替你完成浏览器里的工作，例如填写表单、从多个页面收集信息、整理标签页。它还能截图、为你保存文件。
• 让智能体稍后或按计划执行任务，或监视网页，在你描述的变化出现时收到通知。
• 翻译网页而不破坏页面布局，译文显示在原文旁或替换原文；看视频时也能翻译字幕。翻译引擎由你选择：你的 AI 模型、浏览器的内置翻译器（如有），或免费的在线翻译服务。
• 在页面上选中文本即可使用快捷操作，例如解释、翻译，或按单词在该页面中的含义查词。在哪些网站上显示由你决定。
• 直接从页面开始：浏览器的右键菜单和扩展的工具栏按钮都能带你进入智能体和页面工具。

【智能体、技能与工具】

• 创建拥有自己指令、工具和模型的智能体。智能体可以把工作交给在后台运行的子智能体。
• 技能是可以反复使用的指令：你可以自己选择，也可以让智能体在请求合适时使用。你可以编写自己的技能，并导入或导出。
• 连接 MCP 服务器，为智能体添加更多工具，例如联网搜索。
• 需要精确数字时，智能体可以编写代码，并在你设备上无法访问网络的沙盒中运行。
• 可选的本地执行桥让智能体在你的电脑上运行命令，前提是你自行安装并启用。

【多设备同步】

• 通过浏览器账号或你自己的 WebDAV 存储同步设置、智能体和技能。如果你愿意，也可以同步对话、文件和 API Key；密钥会在你的设备上用你自己的同步口令加密。
• 更改会逐项合并，两台设备上的修改不会互相覆盖。

【一切由你掌控】

• 智能体的每一步都会在运行时显示，并可查看详情。
• 智能体在不确定时，会在提交、购买、发送或删除任何内容之前先询问你。
• 自行运行的任务只读取并报告，除非你允许某个智能体自主操作。
• 界面支持多种语言，并提供浅色和深色主题。

OpenBrowserAgent 是开源项目。源代码、文档和问题反馈：https://github.com/Lumysia/OpenBrowserAgent
