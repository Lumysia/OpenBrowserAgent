OpenBrowserAgent 把 AI 智能体放进浏览器的侧边栏。你可以就当前页面提问、在网上做调研，或者直接把浏览器任务交给它。智能体会阅读页面、点击、输入，并在标签页之间切换，每一步都在你眼前进行。

模型由你自己选择。OpenBrowserAgent 不需要注册账号，也没有自己的服务器：你的消息只会发送到你自己配置的模型提供商、MCP 服务器和同步存储。在其他服务器上的提供商首次接收你的内容之前，你需要为该提供商单独同意；本地模型无需许可。

【能做什么】

• 就当前页面或多个标签页提问：总结、对比、解释、翻译。
• 围绕一个问题在网上调研，得到附带可点击来源的答案。
• 让智能体替你操作浏览器：填写表单、比较商品、从多个页面收集信息、整理标签页并分组。
• 直接在页面上修改内容（例如翻译整个页面），还能截图或下载文件。
• 在任意页面选中文字即可使用快捷操作（解释、翻译、润色、朗读）。此功能默认关闭，需要你手动开启，也可以只在你指定的网站上启用。
• 右键点击页面、链接或所选文本，即可提问、总结、联网搜索，或把页面复制为 Markdown。可以关闭整个菜单或单个菜单项。
• 在右键菜单中翻译页面正文，译文显示在原文旁或替换原文，不改变页面布局，选择“显示原文”即可恢复。之后在同一标签页中打开的页面也会自动翻译，直到重新加载该标签页。可使用你的 AI 模型、浏览器内置翻译器（如有），或 Google、Microsoft 的免费翻译（此时页面文本会发送给它们）。

【智能体与技能】

• 内置“浏览”和“询问”两个智能体。你也可以创建自己的智能体，为它设置专属的指令、工具、模型和私有笔记。
• 智能体可以把工作交给在后台运行的子智能体。
• 技能是可以反复使用的指令。内置技能涵盖填写表单、整理标签页、扩展使用帮助以及编写新技能。输入“/”即可选择技能，也可以让智能体在请求合适时自动调用。技能支持导入和导出。

【你的模型，你的工具】

• 使用你自己的 API Key 和 Base URL，连接 OpenAI 兼容、Anthropic 兼容、Gemini、OpenRouter、DeepSeek、Ollama 等提供商。
• 可以使用更便宜的辅助模型来阅读长页面。
• 连接远程 MCP 服务器（Streamable HTTP），获得更多工具。推荐了无需 API Key 的网页搜索服务器，一键即可添加，每个都默认关闭，由你决定是否开启。
• 精确计算：智能体可以在你设备上的沙盒中运行它编写的 JavaScript 代码（无法访问网络），用于计算、解析表格和转换数据。
• 可选的本地执行桥：让智能体在你的电脑上运行命令，前提是你自行安装并启用。

【多设备同步】

• 通过浏览器账号或你自己的 WebDAV 存储，同步设置、智能体和技能；如果你愿意，还可以同步 API Key（在你的设备上用你自己的口令加密）、对话和文件。
• 更改会逐项合并，两台设备上的修改不会互相覆盖；大批量删除前会先征求你的确认。

【一切由你掌控】

• 每一步工具调用都会实时显示，并可查看详细信息。
• 智能体在不确定时，会在提交、购买、发送或删除之前先询问你。
• 界面支持 English、Deutsch、Español、Français、日本語、한국어、Português (Brasil)、简体中文 和 繁體中文，并提供浅色和深色主题。
