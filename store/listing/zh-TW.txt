OpenBrowserAgent 把 AI 智慧體放進瀏覽器的側邊欄。你可以針對目前的網頁提問、在網路上深入研究，或直接把瀏覽器任務交給它。智慧體會閱讀網頁、點選、輸入，並在分頁之間切換，每一步都在你眼前進行。

模型由你自己決定。OpenBrowserAgent 不需要註冊帳號，也沒有自己的伺服器：你的訊息只會傳送到你自行設定的模型提供者、MCP 伺服器和同步儲存空間。在其他伺服器上的提供者首次接收你的內容之前，你需要為該提供者個別同意；本機模型不需要許可。

【能做什麼】

• 針對目前的網頁或多個分頁提問：摘要、比較、解說、翻譯。
• 針對一個問題在網路上查找資料，取得附上可點選來源的答案。
• 讓智慧體代你操作瀏覽器：填寫表單、比較商品、從多個網頁彙整資訊、整理分頁並分組。
• 直接在網頁上修改內容（例如翻譯整個網頁），還能截圖或下載檔案。
• 在任何網頁選取文字即可使用快速動作（解說、翻譯、潤飾文字、朗讀）。此功能預設為關閉，需要你自行開啟，也可以只在你指定的網站上啟用。
• 在頁面、連結或所選文字上按右鍵，即可提問、摘要、聯網搜尋，或把頁面複製為 Markdown。可以關閉整個選單或個別項目。
• 在右鍵選單中翻譯頁面內文，譯文顯示在原文旁或取代原文，不改變頁面版面，選擇「顯示原文」即可還原。可使用你的 AI 模型、瀏覽器內建翻譯器（如有），或 Google、Microsoft 的免費翻譯（此時頁面文字會傳送給它們）。

【智慧體與技能】

• 內建「瀏覽」和「詢問」兩個智慧體。你也可以建立自己的智慧體，為它設定專屬的指示、工具、模型和私人筆記。
• 智慧體可以把工作交給在背景執行的子智慧體。
• 技能是可以重複使用的指示。內建技能涵蓋填寫表單、整理分頁、擴充功能使用說明，以及撰寫新技能。輸入「/」即可選擇技能，也可以讓智慧體在請求適合時自動使用。技能支援匯入與匯出。

【你的模型，你的工具】

• 使用你自己的 API Key 和 Base URL，連接 OpenAI 相容、Anthropic 相容、Gemini、OpenRouter、DeepSeek、Ollama 等提供者。
• 可以使用較便宜的輔助模型來閱讀長篇網頁。
• 連接遠端 MCP 伺服器（Streamable HTTP），取得更多工具。內建不需 API Key 的網頁搜尋伺服器，每一個都預設關閉，由你決定是否開啟。
• 選用的本機執行橋：讓智慧體在你的電腦上執行指令，前提是你自行安裝並啟用。

【跨裝置同步】

• 透過瀏覽器帳號或你自己的 WebDAV 儲存空間，同步設定、智慧體、技能；如果你願意，也可以同步對話和附件。
• 變更會逐項合併，兩台裝置上的編輯不會互相覆寫；大量刪除前會先徵求你的確認。

【一切由你掌控】

• 每一個工具步驟都會在執行時即時顯示，並可查看詳細資料。
• 智慧體在不確定時，會在送出、購買、傳送或刪除之前先詢問你。
• 介面支援 English、Deutsch、Español、Français、日本語、한국어、Português (Brasil)、简体中文 和 繁體中文，並提供淺色與深色主題。
