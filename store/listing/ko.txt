OpenBrowserAgent는 브라우저 사이드 패널에 AI 에이전트를 더해 줍니다. 지금 보고 있는 페이지에 대해 묻고, 웹 전체에서 조사하고, 브라우저 작업을 맡길 수 있습니다. 에이전트가 페이지를 읽고, 클릭하고, 입력하고, 탭을 오가며 일하는 모든 단계를 직접 지켜볼 수 있습니다.

모델은 직접 준비합니다. 내 API 키로 쓰는 클라우드 AI 제공업체도, 내 컴퓨터에서 실행되는 모델도 됩니다. OpenBrowserAgent에는 계정도, 자체 서버도 없습니다. 내용은 직접 설정한 서비스로만 전송되며, 다른 서버에 있는 AI 제공업체는 그 제공업체에 동의하기 전까지 아무것도 받지 않습니다. 내 컴퓨터나 로컬 네트워크의 모델에는 허용이 필요 없습니다.

할 수 있는 일

• 한 페이지나 여러 탭에 대해 질문: 요약, 비교, 설명, 클릭할 수 있는 출처가 달린 답변.
• 양식 작성, 여러 페이지에서 정보 수집, 탭 정리 같은 브라우저 작업을 에이전트에게 맡길 수 있습니다. 스크린샷을 찍고 파일을 저장할 수도 있습니다.
• 에이전트가 작업을 나중에 또는 일정에 따라 하게 하거나, 페이지를 감시하다가 설명한 변화가 생기면 알림을 받을 수 있습니다.
• 레이아웃을 깨뜨리지 않고 웹 페이지를 번역해 원문 옆이나 원문 자리에 보여 주고, 동영상 자막도 보면서 번역할 수 있습니다. 번역 엔진은 AI 모델, 브라우저의 내장 번역기(제공되는 경우), 무료 온라인 번역 서비스 중에서 고릅니다.
• 페이지에서 텍스트를 선택해 빠른 작업을 쓸 수 있습니다. 설명, 번역, 그 페이지에서의 뜻에 맞춘 단어 찾기 등입니다. 어느 사이트에 표시할지는 직접 정합니다.
• 페이지에서 바로 시작할 수 있습니다. 브라우저의 컨텍스트 메뉴와 툴바에 있는 확장 프로그램 버튼에서 에이전트와 페이지 도구로 이동합니다.

에이전트, 스킬, 도구

• 고유한 지침, 도구, 모델을 가진 에이전트를 만들 수 있습니다. 에이전트는 백그라운드에서 실행되는 하위 에이전트에게 작업을 넘길 수 있습니다.
• 스킬은 다시 쓸 수 있는 지침입니다. 직접 고르거나, 요청에 맞을 때 에이전트가 쓰도록 할 수 있습니다. 나만의 스킬을 작성하고 가져오거나 내보낼 수 있습니다. 또는 작업을 한 번 기록하며 하면, 입력한 내용은 남기지 않고 에이전트가 스킬로 만듭니다.
• MCP 서버를 연결해 웹 검색 같은 도구를 에이전트에 더할 수 있습니다.
• 정확한 수치가 필요하면 에이전트가 코드를 작성해 인터넷에 연결되지 않는 기기 안의 샌드박스에서 실행할 수 있습니다.
• 선택 사항인 로컬 브리지를 쓰면 에이전트가 내 컴퓨터에서 명령을 실행할 수 있습니다. 직접 설치하고 사용하도록 설정한 경우에만 가능합니다.

여러 기기 간 동기화

• 설정, 에이전트, 스킬을 브라우저 계정이나 내 WebDAV 저장소로 동기화합니다. 원하면 채팅, 파일, API 키도 동기화할 수 있으며, 키는 내 기기에서 내 암호 문구로 암호화됩니다.
• 변경 사항은 항목별로 병합되므로 두 기기에서 한 수정이 서로를 덮어쓰지 않습니다.

언제나 내가 주도합니다

• 에이전트의 모든 단계가 실행되는 동안 표시되며, 세부 정보도 볼 수 있습니다.
• 확실하지 않을 때 에이전트는 제출, 구매, 전송, 삭제 전에 먼저 묻습니다.
• 스스로 실행되는 작업은 에이전트가 스스로 작업을 수행하도록 허용하지 않는 한 읽고 보고만 합니다.
• 인터페이스는 여러 언어로 제공되며, 밝은 테마와 어두운 테마가 있습니다.
