OpenBrowserAgent는 브라우저 사이드 패널에 AI 에이전트를 더해 줍니다. 지금 보고 있는 페이지에 대해 묻고, 웹 전체를 조사하고, 브라우저 작업을 통째로 맡길 수 있습니다. 에이전트가 페이지를 읽고, 클릭하고, 입력하고, 탭을 오가며 일하는 모든 단계를 직접 지켜볼 수 있습니다.

모델은 직접 선택합니다. OpenBrowserAgent에는 계정도, 자체 서버도 없습니다. 메시지는 사용자가 직접 설정한 모델 제공업체, MCP 서버, 동기화 저장소로만 전송됩니다. 다른 서버에 있는 제공업체가 처음으로 내용을 받기 전에 제공업체마다 동의를 받습니다. 로컬 모델에는 허용이 필요 없습니다.

할 수 있는 일

• 현재 페이지나 여러 탭에 대해 질문할 수 있습니다. 요약, 비교, 설명, 번역을 해 줍니다.
• 질문 하나로 웹 전체를 조사하고, 클릭할 수 있는 출처가 달린 답변을 받을 수 있습니다.
• 브라우저 작업을 에이전트에게 맡길 수 있습니다. 양식 작성, 상품 비교, 여러 페이지에서 정보 수집, 탭 정리와 그룹화까지 처리합니다.
• 페이지를 그 자리에서 편집할 수 있고(예: 페이지 번역), 스크린샷을 찍거나 파일을 다운로드할 수도 있습니다.
• 어느 페이지에서든 텍스트를 선택하면 빠른 작업(설명, 번역, 문장 다듬기, 소리 내어 읽기)을 사용할 수 있습니다. 이 기능은 직접 켜기 전까지 꺼져 있으며, 원하는 사이트에서만 쓰도록 제한할 수도 있습니다.
• 페이지, 링크, 선택한 텍스트를 마우스 오른쪽 버튼으로 클릭해 질문하고, 요약하고, 웹을 검색하거나 페이지를 Markdown으로 복사할 수 있습니다. 메뉴 전체나 개별 항목을 끌 수 있습니다.
• 페이지 가장자리의 버튼, 툴바 버튼의 메뉴, 키보드 단축키 또는 컨텍스트 메뉴에서 페이지 본문을 번역해 원문과 함께 또는 원문 대신 표시하며, 페이지 레이아웃은 그대로 유지됩니다. "원문 보기"로 되돌릴 수 있습니다. 같은 탭에서 이어서 여는 페이지도 탭을 새로고침할 때까지 번역됩니다. AI 모델, 브라우저의 내장 번역기(지원되는 경우), Google 또는 Microsoft의 무료 번역(이 경우 페이지 텍스트가 해당 회사로 전송됨) 중에서 선택할 수 있습니다.

에이전트와 스킬

• 탐색 에이전트와 질문 에이전트가 기본으로 포함되어 있습니다. 고유한 지침, 도구, 모델, 비공개 메모를 갖춘 에이전트를 직접 만들 수도 있습니다.
• 에이전트는 백그라운드에서 실행되는 하위 에이전트에게 작업을 넘길 수 있습니다.
• 스킬은 반복해서 쓸 수 있는 지침입니다. 내장 스킬로 양식 작성, 탭 정리, 확장 프로그램 도움말, 새 스킬 작성이 제공됩니다. "/"로 스킬을 직접 고르거나, 요청에 맞을 때 에이전트가 알아서 사용하게 할 수 있습니다. 스킬은 가져오기와 내보내기를 지원합니다.

나의 모델, 나의 도구

• 직접 발급한 API 키와 Base URL로 OpenAI 호환 또는 Anthropic 호환 서비스나 로컬 모델에 연결할 수 있습니다.
• 긴 페이지를 읽을 때는 더 저렴한 보조 모델을 사용할 수 있습니다.
• 원격 MCP 서버(Streamable HTTP)를 연결해 도구를 더 늘릴 수 있습니다. API 키가 필요 없는 추천 웹 검색 서버를 클릭 한 번으로 추가할 수 있으며, 추가하면 테스트를 거쳐 켜집니다.
• 정확한 수치: 에이전트가 직접 작성한 JavaScript 코드를 기기 안의 샌드박스(인터넷 접속 불가)에서 실행해 계산하고, 표를 분석하고, 데이터를 변환할 수 있습니다.
• 선택 사항인 로컬 실행 브리지: 직접 설치하고 활성화한 경우에만 에이전트가 내 컴퓨터에서 명령을 실행할 수 있습니다.

여러 기기 간 동기화

• 설정, 에이전트, 스킬을 브라우저 계정이나 직접 운영하는 WebDAV 저장소로 동기화할 수 있습니다. 원하면 API 키(기기에서 직접 정한 암호 문구로 암호화), 채팅, 파일도 동기화할 수 있습니다.
• 변경 사항은 항목별로 병합되므로 두 기기에서 한 편집이 서로 덮어쓰지 않으며, 대량 삭제 시에는 먼저 확인을 요청합니다.

언제나 내가 주도합니다

• 모든 도구 단계는 실행되는 동안 화면에 표시되며, 세부 정보도 확인할 수 있습니다.
• 에이전트는 확실하지 않을 때 제출, 구매, 전송, 삭제 전에 먼저 묻습니다.
• 인터페이스는 English, Deutsch, Español, Français, 日本語, 한국어, Português (Brasil), 简体中文, 繁體中文을 지원하며, 라이트 테마와 다크 테마를 제공합니다.
