OpenBrowserAgent bringt einen KI-Agenten in die Seitenleiste Ihres Browsers. Stellen Sie Fragen zur aktuellen Seite, recherchieren Sie im ganzen Web oder übergeben Sie eine Aufgabe im Browser. Der Agent liest Seiten, klickt, tippt und wechselt zwischen Tabs – und Sie verfolgen jeden Schritt mit.

Das Modell bringen Sie selbst mit: einen KI-Anbieter in der Cloud mit Ihrem eigenen API-Schlüssel oder ein Modell, das auf Ihrem eigenen Computer läuft. OpenBrowserAgent hat kein Konto und keinen eigenen Server. Ihre Inhalte gehen nur an die Dienste, die Sie einrichten, und ein KI-Anbieter auf einem anderen Server erhält nichts, bevor Sie dem für diesen Anbieter zugestimmt haben. Modelle auf Ihrem eigenen Computer oder im lokalen Netzwerk brauchen keine Erlaubnis.

WAS SIE DAMIT TUN KÖNNEN

• Fragen zu einer Seite oder zu mehreren Tabs stellen: Zusammenfassungen, Vergleiche, Erklärungen und Antworten mit anklickbaren Quellen.
• Browserarbeit an den Agenten abgeben, etwa Formulare ausfüllen, Informationen von mehreren Seiten sammeln oder Tabs aufräumen. Er kann auch Screenshots aufnehmen und Dateien für Sie speichern.
• Lassen Sie den Agenten eine Aufgabe später oder nach Zeitplan erledigen oder eine Seite beobachten, und erhalten Sie eine Benachrichtigung, wenn die beschriebene Änderung eintritt.
• Webseiten übersetzen, ohne ihr Layout zu zerstören, neben dem Original oder an seiner Stelle, und Video-Untertitel beim Ansehen übersetzen. Sie wählen die Übersetzung: Ihr KI-Modell, den integrierten Übersetzer des Browsers, wo vorhanden, oder einen kostenlosen Online-Übersetzungsdienst.
• Text auf einer Seite markieren und Schnellaktionen nutzen, etwa ihn erklären, übersetzen oder ein Wort mit der Bedeutung nachschlagen, die es auf dieser Seite hat. Sie legen fest, auf welchen Websites das erscheint.
• Direkt von der Seite aus starten: Das Kontextmenü des Browsers und die Symbolleisten-Schaltfläche der Erweiterung führen zum Agenten und zu den Seitenwerkzeugen.

AGENTEN, SKILLS UND TOOLS

• Erstellen Sie Agenten mit eigenen Anweisungen, Tools und eigenem Modell. Agenten können Arbeit an Subagenten übergeben, die im Hintergrund laufen.
• Skills sind wiederverwendbare Anweisungen: Wählen Sie selbst einen aus oder lassen Sie den Agenten einen verwenden, wenn er zur Anfrage passt. Schreiben Sie eigene und importieren oder exportieren Sie sie.
• Verbinden Sie MCP-Server, um dem Agenten weitere Tools zu geben, etwa die Websuche.
• Für genaue Zahlen kann der Agent Code schreiben und ihn in einer Sandbox auf Ihrem Gerät ausführen, die keinen Internetzugriff hat.
• Mit einer optionalen lokalen Bridge kann ein Agent Befehle auf Ihrem Computer ausführen – erst, nachdem Sie sie installiert und aktiviert haben.

SYNCHRONISIERUNG ÜBER GERÄTE HINWEG

• Synchronisieren Sie Einstellungen, Agenten und Skills über Ihr Browserkonto oder Ihren eigenen WebDAV-Speicher. Auf Wunsch auch Ihre Chats, Dateien und API-Schlüssel; Schlüssel werden auf Ihrem Gerät mit Ihrer eigenen Passphrase verschlüsselt.
• Änderungen werden Eintrag für Eintrag zusammengeführt, sodass sich Bearbeitungen auf zwei Geräten nicht gegenseitig überschreiben.

SIE BEHALTEN DIE KONTROLLE

• Jeder Schritt des Agenten wird angezeigt, während er läuft, mit seinen Details.
• Ist sich der Agent unsicher, fragt er nach, bevor er etwas absendet, kauft, verschickt oder löscht.
• Aufgaben, die selbstständig laufen, lesen und berichten nur, es sei denn, Sie erlauben einem Agenten, selbstständig zu handeln.
• Die Oberfläche gibt es in vielen Sprachen, mit hellem und dunklem Design.
