OpenBrowserAgent puts an AI agent in your browser's side panel. Ask about the page you're on, research a question across the web, or hand over a task in the browser. The agent reads pages, clicks, types and moves between tabs while you watch every step.

You bring your own model: a cloud AI provider with your own API key, or a model running on your own computer. OpenBrowserAgent has no account and no server of its own. Your content goes only to the services you set up, and an AI provider on another server receives nothing until you agree to it for that provider. Models on your own computer or local network need no permission.

WHAT YOU CAN DO

• Ask about one page or several tabs: summaries, comparisons, explanations, and answers with clickable sources.
• Let the agent do browser work for you, such as filling in forms, collecting information from several pages or tidying your tabs. It can also take screenshots and save files for you.
• Translate web pages without breaking their layout, next to the original or in its place, and translate video subtitles while you watch. You choose the engine: your AI model, the browser's on-device translator where available, or a free online translation service.
• Select text on a page for quick actions, such as explaining it, translating it or looking up a word with the meaning it has on that page. You decide on which sites this appears.
• Start from the page itself: the browser's right-click menu and the extension's toolbar button lead to the agent and the page tools.

AGENTS, SKILLS AND TOOLS

• Create agents with their own instructions, tools and model. Agents can hand work to sub-agents that run in the background.
• Skills are reusable instructions: pick one yourself, or let the agent use one when a request fits. Write your own, and import or export them.
• Connect MCP servers to give the agent more tools, such as web search.
• For exact numbers, the agent can write code and run it in a sandbox on your device that has no internet access.
• An optional local bridge lets an agent run commands on your computer, only after you install and enable it.

SYNC ACROSS DEVICES

• Sync settings, agents and skills through your browser account or your own WebDAV storage. If you choose, also sync your chats, files and API keys; keys are encrypted on your device with your own passphrase.
• Changes merge item by item, so edits on two devices don't overwrite each other.

YOU STAY IN CONTROL

• Every step the agent takes is shown as it runs, with its details.
• When it's unsure, the agent asks before submitting, buying, sending or deleting anything.
• The interface is available in many languages, with light and dark themes.

OpenBrowserAgent is open source. Source code, documentation and issue tracker: https://github.com/Lumysia/OpenBrowserAgent
