OpenBrowserAgent puts an AI agent in your browser's side panel. Ask about the page you're on, research across the web, or hand over a browser task. The agent reads pages, clicks, types and moves between tabs while you watch every step.

You bring your own model. OpenBrowserAgent has no account and no server of its own: your messages go only to the model providers, MCP servers and sync storage that you set up. Before a provider on another server first receives your content, you agree to it for that provider; local models need no permission.

WHAT YOU CAN DO

• Ask about the current page or several tabs: summaries, comparisons, explanations, translations.
• Research a question across the web and get an answer with clickable sources.
• Let the agent do browser work: fill in forms, compare products, collect information from several pages, tidy and group your tabs.
• Edit a page in place, for example to translate it, and take screenshots or download files.
• Select text on any page for quick actions (explain, translate, improve wording, read aloud). This is off until you turn it on, and you can limit it to the sites you choose.
• Right-click a page, link or selected text to ask about it, summarize it, search the web about it, or copy the page as Markdown. You can turn the menu or single items off.
• Translate a page's content with the button on the page's edge, a keyboard shortcut or the right-click menu, next to the original or in its place, without changing the page's layout, and go back with "Show original". The next pages you open in that tab are translated too, until you reload it. Use your AI model, the browser's on-device translator where it has one, or Google's or Microsoft's free translation (the page text is then sent to them).

AGENTS AND SKILLS

• Browse and Ask agents are included. You can create your own with their instructions, tools, model and private notes.
• Agents can hand work to sub-agents that run in the background.
• Skills are reusable instructions. Built-in skills cover filling forms, tidying tabs, help with the extension, and writing new skills. Pick a skill with "/", or let the agent use one when a request fits. Skills can be imported and exported.

YOUR MODELS, YOUR TOOLS

• Connect OpenAI-compatible or Anthropic-compatible services, or a local model, with your own API keys and base URLs.
• Use a cheaper helper model for reading long pages.
• Connect remote MCP servers (Streamable HTTP) for extra tools. Keyless web search servers are recommended and added with one click, and each stays off until you turn it on.
• Exact numbers: the agent can run JavaScript it writes in a sandbox on your device, with no internet access, to calculate, parse tables and reshape data.
• Optional local execution bridge: lets an agent run commands on your computer, only after you install and enable it.

SYNC ACROSS DEVICES

• Sync settings, agents and skills through your browser account or your own WebDAV storage; if you choose, also API keys (encrypted on your device with your own passphrase), chats and files.
• Changes merge item by item, so edits on two devices don't overwrite each other, and large deletions ask you first.

YOU STAY IN CONTROL

• Every tool step is shown as it runs, with its details available.
• The agent asks before submitting, buying, sending or deleting when it's unsure.
• Interface in English, Deutsch, Español, Français, 日本語, 한국어, Português (Brasil), 简体中文 and 繁體中文, with light and dark themes.

OpenBrowserAgent is open source. Source code, documentation and issue tracker: https://github.com/Lumysia/OpenBrowserAgent
