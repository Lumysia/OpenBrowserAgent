OpenBrowserAgent 0.1.0: Chrome Web Store "Privacy practices" tab
================================================================

SINGLE PURPOSE
--------------
OpenBrowserAgent is an AI assistant in the browser's side panel. The user connects their own AI model provider, then asks questions about the pages they have open or asks the agent to carry out tasks in the browser (reading pages, filling in forms, managing tabs), watching every step as it runs.


PERMISSION JUSTIFICATIONS (same order as the store page; each under 1000 characters)

== scripting justification ==
Injects the extension's own bundled scripts into the page the user is working on, to read the page text, let the user pick an element, show a page translation the user asked for, and perform the clicks, typing and scrolling the agent's task requires. No code is fetched from a server.

== tabs justification ==
The agent lists, opens, focuses, reloads, navigates and closes tabs when the user asks it to work across pages, and the user can attach open tabs (title and URL) to a chat as context.

== storage justification ==
Saves the user's settings, model providers, agents, skills and chats on the device.

== downloads justification ==
Saves what the user asks for to the browser's Downloads folder: chat exports as Markdown, generated images, diagrams, files the agent downloads from a link, and text or files the agent prepared. The agent reads the state of downloads (finished, failed, where the file was saved) so it can tell the user where the file is, and can cancel or retry the downloads it started. It never opens downloaded files or deletes them.

== unlimitedStorage justification ==
Chats with image and file attachments can exceed the default extension storage quota. They are kept only on the user's device.

== alarms justification ==
While an extension page is open, checks the user's own sync storage for changes once a minute.

== declarativeNetRequestWithHostAccess justification ==
Removes the Origin header from the extension's own requests to an MCP server, only when the user turns on "Send without browser Origin" for that server, because some servers reject browser-origin requests. Each rule matches only that server's URL and only this extension's requests. Other sites and requests are never modified.

== contextMenus justification ==
Adds an OpenBrowserAgent submenu to the right-click menu (the user can turn it off): ask about or summarize the page, translate the page (and show the original again), search the web about it or the selected text, summarize a linked page, or copy the page as Markdown. Items only open the side panel, translate the page or copy to the clipboard when the user picks them.

== nativeMessaging justification ==
Optional local execution bridge: connects to a separately installed helper on the user's computer, only after the user installs it and enables it for an agent.

== search justification ==
Runs web searches through the browser's default search engine (the one the user chose) when the agent needs to look something up.

== tabGroups justification ==
When the user asks the agent to tidy tabs, it groups them and names and colors the groups, and it shows group names in tab lists.

== sidePanel justification ==
The extension's whole interface (chat, agent steps, composer) lives in the browser side panel.

== debugger justification ==
Attached only for the duration of specific actions: trusted mouse and keyboard input on pages that ignore synthetic events (rich text editors, canvas apps), answering a JavaScript dialog that blocks the page, full-page screenshots, and developer diagnostics. It is detached right after the call.

== offscreen justification ==
Converts fetched web page HTML into Markdown text with the browser's DOM parser, which the background service worker lacks. The offscreen document only parses HTML; it shows nothing and loads no remote code.

== Host permission justification ==
The user can ask the agent to read or act on any site they visit, translate any page, and connect any model provider, MCP server or WebDAV sync server by URL. These cannot be known in advance, so access to all URLs is needed. The extension acts on a page only when the user starts a task, attaches the page or translates it.


REMOTE CODE
-----------
Answer: No, I am not using remote code.
All JavaScript is bundled in the package. The extension does not load or eval scripts from any server.
(Note: the agent's optional "run page JavaScript" tool is off by default. When the user enables it, it runs model-written snippets in the web page, not in the extension.)


DATA USAGE: what to tick
------------------------
OpenBrowserAgent has no server of its own, but it does send these kinds of data off the device to services the user configures (their AI provider, MCP servers, sync storage, and the translation engine they pick for page translation). Google counts reading or capturing page content as "handling" user data, so declare these four:

[ ] Personally identifiable information: left unticked; the extension never asks for it (only incidental if the user types it)
[ ] Health information
[ ] Financial and payment information
[x] Authentication information: the user's API keys are sent to the provider they belong to
[x] Personal communications: the user's chat messages to the AI
[ ] Location
[x] Web history: titles and URLs of tabs the user attaches or the agent works in
[ ] User activity: left unticked; the extension doesn't monitor the user's clicks or keystrokes (the agent's own actions are not user activity)
[x] Website content: page text, screenshots and selected elements sent to the user's AI provider; the text of pages the user translates, sent to the translation engine they selected (their AI provider by default, or Google's or Microsoft's free translation service if they pick one; when the picked one fails on a page, the other one translates the rest of that page)

Certify all three:
[x] I do not sell or transfer user data to third parties, outside of the approved use cases
[x] I do not use or transfer user data for purposes that are unrelated to my item's single purpose
[x] I do not use or transfer user data to determine creditworthiness or for lending purposes

Limited Use: the privacy policy states that the use of information received complies with the Chrome Web Store User Data Policy, including the Limited Use requirements; page text sent to Google or Microsoft for translation is only used to provide the translation the user asked for.
